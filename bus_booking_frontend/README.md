# Bus Booking Frontend

This is the frontend React UI for the Bus Ticket Booking App.
It provides user registration/login, bus search, seat selection, ticket booking, booking history, and payment UI.

## Project Structure

- `src/components/` - UI components for main features
- `src/pages/` - Top-level route pages
- `src/services/` - API handling (calls backend FastAPI)
- `src/App.js` - React Router and layout shell

## Development

```bash
npm install
npm start
```
